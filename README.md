# IT Support Portfolio — Gabriel Díaz

Portafolio práctico de un proceso de transición hacia roles de **IT Support / Help Desk**, construido sobre un laboratorio real de Active Directory en Hyper-V, práctica con herramientas de ticketing (Jira Service Management) y herramientas de soporte remoto (RDP / AnyDesk).

Todo el contenido aquí refleja trabajo hands-on realizado en un entorno virtualizado propio, no un curso teórico.

## Contenido

| Carpeta | Descripción |
|---|---|
| [`docs/active-directory`](./docs/active-directory) | Casos de estudio de troubleshooting real en un laboratorio de AD/DNS/DHCP sobre Hyper-V (dominios, OUs, grupos AGDLP, GPOs, delegación de control) |
| [`docs/jira`](./docs/jira) | Práctica de Jira Service Management: colas, JQL, SLAs, reportes y resolución simulada de tickets |
| [`docs/remote-access`](./docs/remote-access) | Comparativa práctica RDP vs AnyDesk |
| [`docs/macos-vs-windows`](./docs/macos-vs-windows) | Tabla de equivalencias Windows ↔ macOS para soporte multiplataforma |
| [`Portafolio_IT_Support.docx`](./docs/Portafolio_IT_Support.docx) | Documento consolidado con las tres secciones (AD, Jira, Remote Access Tools) |

## Stack del laboratorio

- **Hyper-V** — virtualización de Windows Server y clientes
- **Windows Server (AD DS, DNS, DHCP, Print Services)** — Domain Controller y servicios de infraestructura
- **Jira Service Management** — mesa de ayuda / ticketing
- **RDP / AnyDesk** — soporte remoto

# Jira Service Management — Práctica de mesa de ayuda

Práctica en Jira Service Management simulando el flujo completo de un equipo de soporte.

## Temas cubiertos

- Request Types: Incident vs Service Request
- Colas (Queues) con filtros JQL
- Configuración de SLAs (condiciones de inicio/pausa, comentarios internos vs públicos)
- Resoluciones y reportes (SLA cumplido vs incumplido)
- Ciclo de vida de un ticket: resuelto, duplicado, escalado, rechazado — y criterios de escalamiento

Contenido detallado disponible en la sección correspondiente de [`Portafolio_IT_Support.docx`](../Portafolio_IT_Support.docx).

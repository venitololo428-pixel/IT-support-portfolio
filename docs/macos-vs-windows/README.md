# Windows ↔ macOS — Tabla de equivalencias

Repaso conceptual de equivalencias entre Windows y macOS para soporte multiplataforma (sin acceso a hardware Mac físico).

| Windows | macOS | Notas |
|---|---|---|
| Panel de Control / Configuración | Preferencias del Sistema (System Settings) | Ambos centralizan configuración de red, usuarios, actualizaciones |
| Active Directory | Open Directory / gestión vía MDM (Jamf, Apple Business Manager) | macOS rara vez usa AD nativo en entornos modernos |
| Administrador de tareas | Monitor de Actividad (Activity Monitor) | Gestión de procesos y rendimiento |
| Explorador de archivos | Finder | Navegación de archivos |
| CMD / PowerShell | Terminal (zsh/bash) | Línea de comandos |
| Registro de Windows | defaults / plist files | Configuración a nivel de sistema |
| Instalador .msi / .exe | .pkg / .dmg | Instalación de software |
| Actualizaciones de Windows | Software Update | Gestión de parches del sistema |
| Firewall de Windows | Firewall de macOS (en Seguridad y Privacidad) | Seguridad de red local |

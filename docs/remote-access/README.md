# Herramientas de Soporte Remoto — RDP vs AnyDesk

Comparativa práctica de dos herramientas de acceso remoto usadas en soporte técnico.

| | RDP | AnyDesk |
|---|---|---|
| Red | Misma red / VPN | Internet (cualquier red) |
| Autenticación | Usuario y contraseña de dominio/local | Código de ID + autorización en tiempo real |
| Aprobación del usuario remoto | No requiere aprobación en tiempo real | Requiere autorización explícita de la persona del otro lado |
| Caso de uso típico | Soporte interno dentro de la red corporativa | Soporte remoto a usuarios fuera de la red (ej. trabajo desde casa) |

Detalle completo en la sección correspondiente de [`Portafolio_IT_Support.docx`](../Portafolio_IT_Support.docx).
